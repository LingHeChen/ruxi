# 潮汐旅馆：第九声钟响

单人悬疑调查故事，建议完整阅读与查证预计 30～60 分钟。玩家扮演声音记者徐闻，暴雨封岛之夜赴作家江临的约，却在第九声钟响后听说对方失踪。画面采用海岛旧旅馆、冷色海雨与暖色室内灯的统一方向。

- 8 个场景：接待厅、海景餐厅、二楼走廊、209客房、护理室、地下机房、阁楼资料室、旧船屋。
- 4 位在场 NPC：旅馆经营者林素、护士陈雾、电工赵朔、退休船长何泊。人物采用预设条件对话，掌握新证据后可以回访，不依赖运行时大模型。此本的 NPC 留在各自场景，不作随机移动。
- 32 项有独立叙事反馈的预设互动、23 条线索、密码互动与一次可选概率判定。
- 26 张采用的 AI 生成图片覆盖所有场景、NPC、预设互动、关键证物与结局。每次互动都有配图绑定；相关交互共用同一证物/人物图，三个关键段落使用专门剧情图。
- 3 个最终抉择结局、提前离岛、调查未完成，共 5 种结局。

时长是阅读与探索估计，不是经真人计时确认的结论。8817字核心开场与行动叙事，加上线索回看、结局、场景描述与约48次行动，正常阅读约25～35分钟，探索、比对及回访约10～20分钟。快速跳过全文或提前离岛会明显短于30分钟，不强迫玩家等倒计时。

## 图片与复现

图片通过内置 `image_gen` 服务生成，最终素材存于 `apps/mobile/assets/stories/tide_hotel/`。完整提示词见 `art-prompts.json`，修订提示见 `art-revisions.json`。文字证据由游戏文本准确提供，纸面图不承担可读文字或密码校验，图片不包含服务端密码。

`story.json` 是可直接导入工作台的完整 C3 内容。`python3 scripts/build_tide_hotel.py` 根据作者文本和已经落盘的图片生成 JSON 与图片哈希清单；该命令不重新调用生成服务。更换素材需新建版本文件，避免改变已经冻结的故事画面。

`node scripts/publish_tide_hotel.mjs` 在本地已有 Core 和忽略目录的管理员凭据下发布，并通过真实 HTTP 验证五条路线。素材发布只允许与服务端内置清单匹配的图片；任意远程 URL、未登记图片与不匹配的哈希不会通过。

## 作者说明：以下包含剧情答案

故事时间为2023年，旧案发生在2008年9月21日。丁远于2016年病逝。年龄与十五年前的经历依此编排。

今夜的失踪与旧案的责任是两条时间线。江临安排预录钟声，后经后山避险；林素人为断电并掩盖旧案，但不能因此推断她在今夜杀害江临。赵世衡曾在22:10活着上岸，22:35被带离，23:05救援被暂停，名单随后改写。现有证据支持重新调查扣留、延误与改写，不能代替具体死因和责任的正式查明。

### 主线依赖与反卡关

1. 林素首访取得209钥匙，才能进入客房。停钟调查与机房日志分别建立时间锚点。
2. 客房稿纸允许核对旧护理页；原始录音允许向何泊核对离开。药物与绳索调查用于排除误导。
3. 客簿给出铁柜密码的月日线索。输入0921可开；六次失败仍可按维护页拆锁。拆锁不需要随机成功。
4. 柜内原始救援页、名单、护理页与录音齐备后保存副本；旧护理页、名单、未寄信与剪线证据齐备后回访林素。
5. 何泊的离开证词加上后山通路证物，允许应急电话确认江临安全。双方时间线、副本与林素回访完成后才能重建并作最终抉择。
6. 修电为可选判定，70%成功。失败仍可手动读取计时卡，两条路线相同地获得关键信息。

阅读弹窗和打开线索/物品/历史不扣余力。图文叙事在单人公共阅读屏障内暂停行动倒计时，回合是离散调查预算，不是现实分钟。正常完整路线约9～10回合，预算为24回合；耗尽预算进入“调查暂时中止”，不假称查明真相。

“提交核实材料”“七日封存交接”“误指今夜谋杀”为三个最终选择；结束操作的风险文字明确说明会结束本次故事。提前离岛也有单独确认。结局后仍可回看自己的手记。
