## 已执行的验证

- Elixir 规则/真实 PostgreSQL 事务测试：三条结局、不可见线索、交付与重复接受、暂停取消交付、原子换角、身份恢复、设备代次、回执幂等、owner fencing、事件游标、晚到 Worker。
- 三个独立游客的真实 HTTP + Phoenix Channels 联调（包含签名视频 Range、字幕、伪造 capability 拒绝及私人媒体越权拒绝）：join_ref/ref、sync_snapshot/sync_complete/sync_ack、heartbeat、授权角色、私有序号不影响他人、10 次重复分享、完整协作、中场、真实 45 秒决策、E1 结算与快照读取。
- Flutter 玩家端与制作台静态分析、Widget/视图归并测试、Web 构建。
- 390×844、大字号 1.6 倍的首页 Widget 布局检查。
- Python Worker/机器契约与 golden fixtures 测试。

具体测试数量与最后构建结果见 `docs/VALIDATION.md`。上述证据不等同于完整 QA01–QA34 通过。

## 尚未完成或未验证

1. **最终媒体与媒体验收**：八段程序化动效明确是开发样片。持续校时、超过 1 秒漂移 seek、运行中连续缓冲 30 秒后授权摘要降级已实现；弱网和真机播放未实测。生产对象存储/CDN、上传/隔离转码/首帧工作流尚未完成。
2. **制作体验**：AST 与交互预览已实现，二人/四人格式有测试，但本次只制作三人剧目。剧目切换、从三人模板创建草稿及会话刷新已有界面。媒体管理、全部结构化效果编辑、预览发布证据及发布后复盘体验仍需补齐。高级 JSON 仍是部分内容的编辑入口。
3. **AI 供应商**：DeepSeek 和兼容服务适配器已有模拟 HTTP 测试；真实密钥已配置，两次合成提示联调通过，完整质量与注入/泄露评估未执行。编辑 AI 与转码任务尚未实现。详见 `AI_CONFIGURATION.md`。
4. **可靠性扩展**：replay join 已通过真实重连联调。单节点 lease/owner fencing 已有，跨节点路由、完整故障演练、Oban 调度、RPO/RTO 备份恢复演练没有完成。生产 SQL 权限拆分待补。
5. **保留与分析**：账号擦除、凭证撤销、共同房间去标识和独立台账重放已有实现及测试。异步埋点及聊天治理已有实现、边界测试与 HTTP 联调。业务统计仍需基于服务端提交事实建立专用去标识投影；云端持久台账及完整容量/性能报告待完成。
6. **物理模型差异**：核心可运行迁移使用 bigint 毫秒时钟和 JSON 进度，未完整铺开设计数据文档中的 timestamptz、媒体资产、权限/权益、选民冻结、内部领域事件等表。固定三席位由冻结房间状态维护。
7. **手机验收**：iOS/Android 真机、来电/后台/锁屏/旋转、播放器释放、Keychain/Keystore/SQLite 实机验证、读屏、30 分钟资源趋势及 100 房压测尚未执行。不能以 Web 构建替代真机验收。
8. **浏览器视觉验收**：当前应用内浏览器不可用（浏览器列表为空）；未声称完成实际浏览器视觉/交互测试。
9. **安全与运营**：失败计数限流、聊天举报/屏蔽与审核已实现；跨节点限流、部署 RBAC 运维与告警、WSS/TLS 代理和签名地址日志检查待验证。当前核心固定单节点。
10. **商业化**：支付、公开匹配、语音、AI 补位不在本版开发范围。
