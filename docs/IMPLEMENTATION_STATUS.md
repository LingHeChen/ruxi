- Elixir 规则/真实 PostgreSQL 事务测试：三条结局、不可见线索、交付与重复接受、暂停取消交付、原子换角、身份恢复、设备代次、回执幂等、owner fencing、事件游标、晚到 Worker。
- 三个独立游客的真实 HTTP + Phoenix Channels 联调（包含签名视频 Range、字幕、伪造 capability 拒绝及私人媒体越权拒绝）：join_ref/ref、sync_snapshot/sync_complete/sync_ack、heartbeat、授权角色、私有序号不影响他人、10 次重复分享、完整协作、中场、真实 45 秒决策、E1 结算与快照读取。
- Flutter 玩家端与制作台静态分析、Widget/视图归并测试、Web 构建。
- 390×844、大字号 1.6 倍的首页 Widget 布局检查。
- Python Worker/机器契约与 golden fixtures 测试。

具体测试数量与最后构建结果见 `docs/VALIDATION.md`。上述证据不等同于完整 QA01–QA34 通过。

## 本轮补齐

- 制作端结构化角色、线索、变量、动作效果编辑；授权上传、文件摘要核验、转码、首帧预览、不可变字幕修订和发布链路。
- 编辑 AI 仅生成选定文本建议，人工确认后按 revision/hash 应用；不修改玩法事实或直接发布。
- Oban 定时维护、租约回收、对象清理、去标识终局统计与 reviewer 运营面板。
- 冻结选民表与数据库约束；接管房间时从 SQL 重建角色、道具、交付、选民和投票事实，校验发布内容 hash。
- 玩家已发布剧目选择、公开提交事件复盘和同剧目再开一局。
- 离线恢复控制、独立擦除台账重放、备份脚本、生产权限模板、CI 和本地故障/恢复/负载演练。

## 发布前仍须验证

1. 实体 Android/iOS 的弱网、来电、后台、锁屏、播放器释放、读屏和 30 分钟资源趋势；构建和 Widget 测试不能替代这些检查。
2. 实际浏览器视觉及完整交互验收：当前应用内浏览器实例不可用。
3. CloudBase 的容器运行、持久对象与独立擦除台账卷、TLS/WSS、数据库连接与权限、备份计划和告警。按用户要求在开发之后执行；云端尚未应用本轮 005–013 增量迁移。
4. 媒体 Worker 已限制协议、进程资源与环境凭证；生产仍须容器隔离。现有原创程序化剧情视频可用于作品展示，未进行演员实拍。
5. 核心明确为单实例部署，未实现跨节点房间路由或分布式失败计数，不允许直接扩容 core 为多实例。
6. 数据模型采用 bigint 毫秒和部分 JSON 恢复缓存；不声称逐字段复刻设计物理模型。结构性提交事实、冻结选民、版本和媒体已落 SQL，权益/支付不在本版范围。
