# C3 开发与验收记录

设计原件：`design/c3_package`，解压自用户提供的 `Ruxi_C3_Design_Package.zip`。原件未修改。C3 是 C2 增量，当前映射为内容 4、引擎 3、协议 3，HTTP 保持 `/api/v2`，Phoenix framing 保持 2.0.0。旧内容 3、引擎 2、协议 2 房间继续按原定义运行。

## 已实现的核心链路

- 原始增量 profile 保存在 `c3`；完整应用契约见 `contracts/c3/story.schema.json`，服务器副本见 `services/core/priv/c3`。`c3_settings` 为完整包中的通路事件、角色、目标、NPC、标签等绑定，`secrets` 仅进入作者/服务器内容。玩家投影和报价不包含 secret_ref、答案或哈希。
- `interaction-quotes` 返回当前角色的费用、格式、次数与公开判定修正，60 秒且不超过步截止。一角色一互动仅保留一个未提交报价。提交前验证协议、控制权、输入、报价依赖和 AP；正确性只在结算时判断。
- 密码保留前导零，支持 exact 与 NFKC→trim→Unicode casefold。原始输入限制 512 字节，规范化后最多 64 code points；拒绝控制字符。有效尝试计费计次，错误格式免费。输入在待执行意图中加密，回执使用服务端 HMAC，不回显答案，结算与取消后移除意图密文。
- 骰子使用服务端安全字节与拒绝采样，1d100≤target，修正后夹到 0–100。房间独立 draw journal 在世界事务前提交，绑定房间/步/意图/slot；恢复读同一条记录。交互意图 ID 由原 command_id 与冻结步确定；规则循环保留冻结意图并挂起。
- 方向通路保留独立 ab/ba 费用与条件。观察快照属于角色，远方不会自动获得返程封路的新状态；移动重新查真实条件，无效退款。世界地点卡固定大小，场景对象改为独立卡片，支持方向/互动检查器、作者遮蔽答案、撤销重做、引用检查删除、角色服务端投影预览、独立布局保存与深链场景入口。
- 固定阵营绑定、个人/阵营/公共目标及终局结果只返回本人；副本知识不会因原件销毁被删除。知识记录区分亲历与转述。NPC 按世界轮次走已声明通路，不因打开面板而推进。
- Flutter 密码与判定面板接真实报价和提交；结果序列按 resolution_id 去重，确认后先关闭输入面板再呈现结果。错误/等待保持当前输入，未发送输入仅在控件内存，退出销毁。新增互动与预设行动默认最多显示三项，其余可展开；个人目标有独立入口。

## 可复现验证

- `mix test`：Core 102 个测试通过，含 C2 回归和 9 个 C3 引擎用例。
- `flutter test`：40 个通过、2 个需要显式开启的本地实时测试跳过；密码面板检查 390/768/1440 逻辑宽度。
- `npm test`：React 管理端 10 个测试通过，含 20 地点、每地 15 对象/10 行动、6 角色的摘要密度组件测试。该测试不等价于真实浏览器视觉验收。
- `node scripts/publish_c3_story.mjs`：真实 HTTP 三人流程，校验能力门禁、私有地图、报价不含答案、格式免费、服务端判定、私有点数、幂等重试、异参冲突、前导零、角色预览以及仅预设行动通关。三人均可经安全出口离馆，修电结果不阻断此路径。摘要证据在忽略目录 `.local/c3/http-evidence.json`。
- `mix run ../../scripts/c3_draw_fault.exs`：真实 PostgreSQL 独立提交，验证世界事务回滚后 draw 存在、恢复得到同一 roll、世界未改动。测试产生独立挂起房间，测试 draw 显式标记 abandoned。
- 本地样例剧目：`http://localhost:8080/stories/74dc1234-d43c-4276-ba60-7256091a4285`；制作台：`http://localhost:8081/stories/74dc1234-d43c-4276-ba60-7256091a4285/world`。

## 本轮尚未完成的 C3 范围

本记录不能用作“C3 全部完成”或正式运营验收。以下仍需实现/完整验证：

- 角色不透明 hinted 地点及替换关系、通路 group_arrival 的完整多人验收、离散痕迹寿命与调查状态。
- 随机秘密阵营分配、阵营频道与策反撤权、通信范围、全体同意的全知复盘。
- 冷却轮次/重置事件的完整作者流程、按 observers/public 受众返回互动结果。
- 可取消的路径模拟任务、全分配与随机失败分支覆盖、发布路径门槛；当前编译器执行形状、引用、类型、秘密隔离与概率公开性检查，不能证明所有故事都可完成。
- 2 秒等待/8 秒主动查询的统一恢复、跨页面未确认命令持久恢复，以及全部 draw 崩溃点、owner 接管与运维修复演练。
- 完整 C3 小说改编、三方合并、受众 AI/语音/字幕缓存验证及 C3 埋点。
- 真实浏览器/读屏/200% 字体、React Flow 大图视觉验收、100 个三人房性能目标。目前自动化浏览器没有可用实例，组件与 HTTP 测试不能替代这项验收。

数据库迁移只扩展 `ruxi` schema；未向 public 写表，未修改旧 release，未部署 CloudBase。
