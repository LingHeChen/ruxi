# C2 实施与验收

权威输入：`docs/design/c2` 原始 C2 文档包；玩法 D02、视觉 D03、协议 D06、DSL D08。工作契约在 `contracts/c2`，样例在 `content/c2`。保持 C1 Schema 2 / 协议 1 与 C2 Schema 3 / 协议 2 分离，C1 已发布内容和活动房不得改写。

实施顺序：

1. 契约与有版本的规则内核：JSON 形状、引用/类型/权限校验、条件效果、地点发现、行动点预留、稳定轮换结算、事件与结局。
2. PostgreSQL `ruxi` schema expand 迁移、房间 fencing/幂等/投影/outbox、`/api/v2` 与 Phoenix 协议 2。
3. Flutter 新版舞台、地图、行动、提案、个人阅读队列、媒体与恢复；玩家入口统一使用新版剧目。
4. React/Ant Design 项目工作台：地点容器、引用定位、结构化编辑、独立布局、自动保存、本地恢复、三方冲突处理、验证/预览/发布。
5. Python 在线判断与小说改编：适配器、来源、检查点、任务 generation、ChangeSet、人工锁定保护。
6. QA01–QA22 端到端、秘密隔离、竞争、模型降级、迁移和恢复；记录真实设备/浏览器及负载证据。

验收约束：queued 只预留、不提前扣 remaining；无效动作退款；概率重试不重抽；事件循环回滚整步；未知实体不能出现在网络投影中；预设操作独立通关；改编不得覆盖锁定字段；布局不进入执行 hash。文档包的参考引擎只覆盖有限子集，不代表生产验收。

当前状态：C2 基线已导入，开发进行中。CloudBase 部署与商业化验收尚未完成。DeepSeek 使用已有服务端适配器和忽略的密钥配置，不向客户端传密钥。所有数据库新增结构继续在 `ruxi`，不使用 `public`。

## 视觉小说舞台与行动回响

游玩页改为全屏场景、底部叙事与选项、已知地点缩略地图、行动点提示与旅途手记。《雨夜最后一封信》使用两张项目专用 imagegen 场景图，移动时淡入切换；其他剧目使用通用场景背景，未套用邮局图。

普通调查直接执行，结果通过独立阅读框呈现，包含逐字显示、显示全文、已获线索提示、继续按钮。最终结局选择及提前结束回合先确认。服务器投影新增 own_results，仅包含当前角色的实际结算状态、成本与行动标签，不含其他角色意图、随机点数或私有世界变量；排队不会显示成功。回合递增由服务器状态驱动，结果阅读后依次显示渐入/停留/渐出的回合过渡，可点击提前继续；结束状态不会错误展示下一回合。阅读提示串行处理，刷新不重复弹出已展示的结算，未确认的服务器阅读队列可恢复。

地图只绘制授权视图中的已知地点与真实通路，突出当前位置；点击地点查看描述、通路及成本，再确认移动。旅途手记包含已获线索、物品与本次阅读记录；多人分享仍要求明确选择接收者。生成素材与剧情均保存在仓库，素材来源见 assets/stories/last_letter/README.md。修复私有媒体角色数组校验与阅读 text 字段显示。

本地剧目已发布新冻结版本；旧房间保持原剧本版本，新创建房间获得独立行动叙事。单人两条主动结局和三人 Flutter 数据客户端通关恢复通过。Core 92 项测试通过，Flutter 31 项常规测试通过（2 项依赖本地服务的测试默认跳过）、分析通过、生产构建完成；交互测试覆盖线索弹出/旧结果去重/地图确认/回合自动淡出。1280px 与 390px 舞台和对话框截图由原生 widget 渲染生成，位于 `.local/ui-review`；未将它们当作真实浏览器验收。


## 三个游戏面板与单人体验重写

原来的混合旅途手记已移除。游玩顶部有线索册、随身背包、行动记录三个入口；线索/物品采用格子和选中详情，桌面左右分区、手机上下分区，面板内部也可切换分类。线索只包含已获信息，背包只包含实际持有物品，分享需明确接收人；历史来自服务器投影，最近 80 个结算中的个人行动按时间展示，含成本与成功状态，不依赖当前页面本地日志。可选的线索 label 和物品 description 已加入运行契约、作者 Schema 与授权投影；未修改原始 C2 设计包。

《雨夜最后一封信》重写为三幕：新邮戳建立送信人疑问；抢救投递簿或录音带互斥；判断母亲离开的原因；合照记忆与实际保存的证据改变告别。八条选择组合产生六个主动结局文本变体，另有超时结局；不完整判断可以重新思考。读信获得实物钥匙并发现档案室，地图通路检查持有钥匙。雨水、停电、场景亮度、章节与当前场景描述随时间/进度改变。单人隐藏手动结束回合，调查推动时间，需要时提供真实场景等待行动。用完次数的行动不再堆积为灰色按钮。新版已在本地发布，旧房间继续保留冻结版本。
