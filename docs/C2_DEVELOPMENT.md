# C2 实施与验收

权威输入：`docs/design/c2` 原始 C2 文档包；玩法 D02、视觉 D03、协议 D06、DSL D08。工作契约在 `contracts/c2`，样例在 `content/c2`。保持 C1 Schema 2 / 协议 1 与 C2 Schema 3 / 协议 2 分离，C1 已发布内容和活动房不得改写。

实施顺序：

1. 契约与有版本的规则内核：JSON 形状、引用/类型/权限校验、条件效果、地点发现、行动点预留、稳定轮换结算、事件与结局。
2. PostgreSQL `ruxi` schema expand 迁移、房间 fencing/幂等/投影/outbox、`/api/v2` 与 Phoenix 协议 2。
3. Flutter C2 舞台、地图、行动、提案、个人阅读队列、媒体与恢复；保留 C1 路由。
4. React/Ant Design 项目工作台：地点容器、引用定位、结构化编辑、独立布局、自动保存、本地恢复、三方冲突处理、验证/预览/发布。
5. Python 在线判断与小说改编：适配器、来源、检查点、任务 generation、ChangeSet、人工锁定保护。
6. QA01–QA22 端到端、秘密隔离、竞争、模型降级、迁移和恢复；记录真实设备/浏览器及负载证据。

验收约束：queued 只预留、不提前扣 remaining；无效动作退款；概率重试不重抽；事件循环回滚整步；未知实体不能出现在网络投影中；预设操作独立通关；改编不得覆盖锁定字段；布局不进入执行 hash。文档包的参考引擎只覆盖有限子集，不代表生产验收。

当前状态：C2 基线已导入，开发进行中。CloudBase 部署与商业化验收尚未完成。DeepSeek 使用已有服务端适配器和忽略的密钥配置，不向客户端传密钥。所有数据库新增结构继续在 `ruxi`，不使用 `public`。
