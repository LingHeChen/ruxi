# C1 完整开发计划

2026-10-08。用户已授权继续完成六份设计文档定义的首版开发。主规范为产品、技术、数据、接口、UI 和测试文档的 C1 修订。

## 范围与完成口径

首版为原创三角色样片，正式支持 Android/iOS 玩家端及 Web 制作台。内容格式校验覆盖 2–4 席位，但不额外制作二人或四人剧目。支付、语音、公开匹配、AI 补位属于后续阶段，不计入本次。

完成分为功能实现和验收通过两项，分别记证据；缺少设备、部署或模型凭证的验收不得标成通过。不能以测试数量、构建成功或样片玩法闭环代替 QA01–QA34。

## 开发批次与核对

| 批次 | 实际交付 | 主要验收 |
| --- | --- | --- |
| 1 产品与制作 | 结构化角色/阶段/动作/可见性/媒体表、关系图、隔离的三角色交互预览、复盘与状态体验 | P09/P10、QA03/21/25–27/33 |
| 2 内容协议 | 白名单 AST、类型与引用校验、有界状态遍历、结局可达性、编译 hash、拒绝未知字段 | QA06/21/30 |
| 3 媒体和 AI | 上传意图、实际文件核验、隔离转码/首帧/字幕任务、权限绑定、持续播放锚修正、受限供应商适配和编辑辅助 | QA16–20/22/23 |
| 4 生命周期与可靠性 | replay 同步、背压、作业恢复、完整数据约束、SQL 权限拆分、诊断和失败限流 | QA05/07–15/31/32 |
| 5 数据与运营 | 7 天正文/事件、180 天复盘、30 天回执清理，账号擦除及恢复清单，异步有界埋点，聊天治理 | QA18/23/24/29/34 |
| 6 发布验收 | 自动化三结局、并发屏障、定向变异、100 活跃房负载、备份恢复演练、真机与读屏证据 | QA01–QA34 全量复核 |

## 本轮进展

上述功能批次现已补齐，包括素材流水线、制作建议、公开复盘、运营维护和离线恢复。验收工具覆盖真实三结局、故障、备份及持续负载；设备、实际浏览器和云端资源验证仍独立记录，不能以实现完成代替上线批准。

## 历史工时估计

以已有样片实现和联调约一小时的实际推进速度为参考，当前估计剩余开发 20–35 小时、验收及修复 8–16 小时，合计 28–51 小时，约 3–6 个完整工作日。置信度低，后续按每批实际耗时调整；这不是交付保证，也不是后台自动持续运行承诺。真实素材、模型凭证、生产资源及四台真机的等待时间另计。

## 记录方式

每批更新实现状态、机器契约及对应测试。QA 的复合子项分别记 PASS/FAIL/NOT_RUN/BLOCKED，未经完整执行不得将整个 QA 记 PASS。最终发布判断遵守测试文档 G0/G1 门槛。
