# CloudBase 接入语义检查

2026-10-08，检查范围为本轮已完成的数据库迁移、生产配置与容器源文件。

|规则|检查结果|
|---|---|
|SEC001|核心与 Worker 的健康接口仅返回固定健康信息或统计，不反射完整请求头、平台上下文或环境变量。生产镜像不复制 `.env`。|
|PG-CR001|先查询现有对象，再新建独立 schema，通过版本迁移明确创建全部业务表，成功后复核 25 张表。|
|PG-CR002|浏览器不直连数据库。ruxi schema 对 anon/authenticated 拒绝访问，后端执行应用层身份、房间成员、设备代次与管理员角色校验。未以“仅开启 RLS”替代授权。|
|PG-CR003–005|当前未实现 pgstore 上传，因此不添加共享存储宽泛权限。后续上传接入须单独检查 bucket、对象路径及 storage.objects 策略。|

实际部署仍缺直连凭据、受支持的数据库网络路径及注销台账持久存储。
当前平台数据库角色不具备 CREATEROLE 权限，不能通过 SQL 自建业务登录账号绕过控制台凭据配置。
尚未进行生产容器、云端连接、托管域名与上传链路验收；本记录不代表项目生产就绪。
