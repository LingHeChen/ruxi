2 环境 数据与执行方法
项
固定配置与记录
身份
A 调查员、B 乘客、C 乘务员，三个独立账号和设备；D 为陌生账号；A2 为 A 的第二设备。禁止同账号三窗口代替三名玩家。
服务
测试 Core、真实 PostgreSQL、Python worker、隔离对象存储；记录镜像 digest、提交 SHA、迁移版本、配置 hash 和依赖锁文件。
样片
冻结 V1 内容 hash，准备 E1/E2/E3、坏图与发布后 V2。每次新 room；私有字段含唯一 canary 字符串，用于抓包和日志检索。
观察
有权限的测试观察器读 DB 事实和成员事件；不能通过玩家接口读取全量 state。原始敏感证据放隔离目录，对外报告脱敏。
故障
仅测试环境提供提交前/后屏障、outbox 暂停、单条广播丢弃、worker 延迟和 DB 断连；故障开关不得进入公开生产接口。
时间
规则单测可用可控时钟；锁等待和截止集成必须真实 DB 时钟。长周期用测试专属过期 fixture 加速，并补至少一次真实短时计时验证。
测试分层：纯规则验证确定性；真实 DB 事务验证唯一键与竞态；Channel/HTTP 验证契约与授权；三个客户端验证完整流程；真机验证播放器、生命周期、手势和性能。不能用 SQLite 或 mock repository 代替 PostgreSQL 锁竞争证据。
并发用屏障同时释放两个请求，记录锁取得和 DB 决策时间；不以随机 sleep 碰运气。重试同 ID 的期望由人工 fixture 固定，禁止让同一实现函数既生成结果又生成唯一预期。每个失败保留最小序列和 seed。
网络配置拟定为 N0 同区域稳定网络、N1 RTT 300ms 加抖动100ms及2%丢包、N2 完全断网10/119/121秒、N3 可用带宽512Kbps。记录注入层及实际测量，N1—N3验证正确性和降级，不套用N0延迟门槛。
每个用例结束清理自己的房间、任务与临时对象；发现失败先保存证据再清理。不得连接生产库做故障注入。自动化运行应可重复，环境无资源或设备缺失记 BLOCKED，不记产品缺陷或通过。
3 建房与完整玩法

QA02 三角色协作与真相
映射 P03 P05 T01 D03  |  默认状态 未执行

步骤：1 C 提前开柜；2 A 调查并公开 C1；3 B 调查 C2 并交付 C，C 接受；4 C 开柜并公开 C3；5 全员提前结束探索并确认中场，再两票 publish。
通过条件：提前开柜拒绝且不消耗；C2 唯一归 C，B 保留已知描述；C3 公开后 publish 才可选；截止后 E1，片段和复盘对应真相。
证据：三端操作录屏、每步授权快照、物品 owner/version、settlement。
QA03 结局与不可回溯
映射 P04 P05 P10 T05  |  默认状态 未执行

4 隐私与认证
QA04 全链路私有信息隔离
映射 P02 P10 T02 D07 A02 A08  |  默认状态 未执行
前置：A 私有 C1、B 私有 C2；为正文/资产设置 canary。
步骤：1 抓三端 WS/HTTP；2 D 与 B 请求 A 的 snapshot/events/receipt/media；3 B 伪造 topic/actor/room；4 A 私有调查、提示和改票；5 重连与结局复盘。
通过条件：B/C/D 的 payload、错误、日志和媒体摘要不含 A canary；无隐藏事件占位；A 私有动作不增长他人 seq；复盘也不公开未共享秘密。
证据：脱敏抓包及 canary 扫描结果；同时给出 A 能正常读取的正对照。

5 并发与幂等

映射 P04 T03 D04 A04 A05  |  默认状态 未执行

步骤：1 同 ID 并发十次；2 提交后丢回复，查回执并重发；3 相同 ID 改 payload；4 分别让回执/事件先到；5 接管后以新代次重试。
通过条件：一次业务效果；相同载荷返回原结果，变更载荷冲突；UI 不重复应用或重播成功动画；新控制代次可确认旧意图；查询不存在不触发新 ID。
证据：命令行数、owner/票型、view_seq 和 UI pending 时间线。
QA08 交付竞态与取消
映射 P04 T04 D05 A10 H03  |  默认状态 未执行

步骤：独立重置场景后运行 accept 对 accept、accept 对 expiry、accept 对 pause；再测 reject、cancel、30 秒过期和旧 offer 重用。
通过条件：最终仅一个 owner 和 offer 终态；接受才增 item version；拒绝/取消/过期不转移；暂停解除锁定；旧 offer 不能复活。
证据：并发屏障、事务时间、item 与 offer 行、双方投影；每种竞态各留结果。
QA09 截止时刻与重复结算
映射 P04 P05 T05 D06 D12 A09  |  默认状态 未执行
前置：decision 截止在未来；测试可持有 room 行锁。
步骤：1 投票在截止前进入但被锁阻塞，截止后放锁；2 同时唤醒两个截止任务；3 提前/恰好截止/晚于截止分别投票；4 截止前改票。
通过条件：以取得锁后的 DB 时间为准，时间≥deadline 拒绝；一次 settlement；改票仅保留最后有效票；客户端改时钟不能延长投票。
证据：DB clock、锁时间、投票行、settlement 唯一键及 E 结局。
6 同步与持久恢复
QA10 快照期间继续变更
映射 P06 T06 D08 D09 A06  |  默认状态 未执行
前置：A 有 last_seq；B/C 可产生公共变更。
步骤：1 在订阅后读快照屏障暂停 A 同步；2 B/C 操作；3 释放并加入乱序/重复广播；4 sync_complete 前强发命令。

QA11 丢尾事件 历史清理与背压
映射 P06 T07 D13 A07 A14 A15  |  默认状态 未执行

QA12 提交前后崩溃与数据库故障

通过条件：合法聊天仅固定成员可见，按纯文本显示；超长/超频受限且草稿保留；AI 输入无其他角色秘密，输出非法引用/patch 不执行；日志不泄露正文。
证据：长度边界、限流计数、三端消息、模型输入输出验收记录。
9 媒体与内容发布
QA19 双端播放与授权降级
映射 P07 T12 A13  |  默认状态 未执行
前置：八段视频、字幕及同视角摘要就绪；Android/iOS 真机。
步骤：1 播公共/私有片段；2 使 CDN 失败 30 秒；3 开摘要完成；4 过期 URL 刷新；5 他人请求私有字幕；6 来电、锁屏、前后台。
通过条件：可用视频正常解码；摘要只属授权视角；不能本机回调直接推进全房；旧控制设备不签新 URL；恢复无双播放器或后台残留声音。
证据：真机录屏、授权请求、控制器数量、音频焦点与解码日志。
QA20 媒体时间锚与播放漂移
映射 P07 T12  |  默认状态 未执行
前置：三端校时，可注入 200/700/1500ms 漂移。
步骤：1 公共锚未来 start_at；2 分别注入三档偏差；3 暂停恢复换锚；4 私人片段独立进度；5 连续旋转/布局变宽。
通过条件：未到 start_at 不抢播；小偏差不抖动，大偏差按策略修正；私有片段不强行同步；只保留一个播放器实例，布局不重置进度。
证据：锚、RTT/offset、实际播放位置和控制器跟踪；不以 Flutter 帧率代替视频同步指标。
QA21 坏图阻断与不可变发布
映射 P09 T11 A13  |  默认状态 未执行
前置：editor/reviewer/publisher 分权；V1 已有活动房。
步骤：1 导入缺角色/未知引用/不可达结局/缺默认选项/未就绪资产；2 审核后改草稿再发布；3 并发保存 revision；4 发布 V2、回滚指针、blocked V1。
通过条件：坏图拒绝；审批 hash 不匹配拒绝；并发编辑不覆盖；旧房仍 V1；blocked 挂起尚未结算房间并禁止新资源；无权者不能发布。
证据：验证报告、三角色预览、hash/revision、审计与旧房引用；后台登录及业务幂等见 QA33。
10 数据与灾难恢复
QA22 数据库约束与事务原子性
映射 D01—D06 D08 D12  |  默认状态 未执行
前置：真实 PostgreSQL 和受限测试 DB 账号。
步骤：1 插跨房 member FK、重复角色、重复 pending offer、重复 settlement；2 在业务事务各持久化步骤故障；3 并发独立调查。
通过条件：非法关系不能保存；回滚后快照、结构化事实、回执、事件和 outbox 无半成品；独立调查不因无关全房 revision 被拒。
证据：SQL 错误、事务前后摘要、锁等待；禁止只断言 HTTP 状态。
QA23 清理 账号擦除与历史
映射 P10 D13 A14  |  默认状态 未执行
前置：活动/挂起/终态房间分别准备；含聊天和提示副本。
步骤：1 运行保留期清理；2 用旧游标补发；3 擦除账号；4 检查快照、事件、任务、对象和日志；5 查询他人共享结果。
通过条件：活动恢复数据不误删；仅连续前缀推进 floor；过期正文所有副本清理；会话撤销，墓碑 ID 不复用；不盲删其他成员共同结果。
证据：清理前后计数、canary 扫描、撤销记录；保留规则未批准不可正式发布。
QA24 迁移与备份恢复演练
映射 P06 D14 D15 A14  |  默认状态 未执行
前置：备份、WAL、对象、独立擦除清单；记录最新已确认提交时间。
步骤：1 旧快照 upcast 并比较结局；2 隔离恢复到选定时间；3 重放擦除清单，废弃租约/凭证；4 更换 recovery_epoch；5 原成员重新认证。
通过条件：迁移保持玩法语义；资产引用可读；尚未结算活动房先挂起，ending 保留结算并按截止完成；旧 pending 不自动重放；旧 token/worker/owner 无效；RPO=故障发生时间−最后可恢复提交时间，空闲期另记真实丢失事务数；RTO=故障发生至原成员可恢复服务的时间；目标分别≤5min/≤60min。
证据：演练起止、最后恢复提交点、校验摘要、失败与重试记录；不能仅凭备份成功日志判恢复成功。
11 UI 动效与无障碍
QA25 组件状态与反馈真实性
映射 P03 P04 H01—H04 A05  |  默认状态 未执行
前置：UI 图稿和 tokens 固定，网络可延迟与拒绝。
步骤：逐一触发按钮/卡片/输入/弹窗的默认、按下、禁用、pending、成功、错误；公开前取消；交付等待时返回；投票失败后恢复。
通过条件：等待不显示成功；2 秒确认提示、8 秒未知结果按协议；公开必须确认范围；失败保留内容；道具不预先转移；重复回执不重播动画。
证据：状态截图矩阵、录屏与相应命令/事件时间；HTML 的 750ms 不成为产品固定延迟。
QA26 布局迁移与可中断动画
映射 P07 H05 H06  |  默认状态 未执行
前置：360×800、390×844、600×960、1024×768 和低高度横屏。
步骤：1 输入草稿并滚动线索；2 断点附近连续缩放；3 面板展开中反向关闭/拖动；4 视频播放时重排；5 多人事件在转场中到达。
通过条件：无溢出或幽灵点击层；草稿、焦点、选中 ID、滚动、播放器和 pending ID 保留；无重复命令/订阅；从当前动画进度反向，窗体持续缩放不堆动画。
证据：五尺寸录屏、命令计数、控制器/订阅数量；侧栏宽度按实际 constraints。
QA27 读屏 大字与减少动态
映射 H06 UI 第9节  |  默认状态 未执行
前置：Android TalkBack 与 iOS VoiceOver；200% 字号。
步骤：1 完成建房至投票核心流程；2 模态打开/关闭和返回；3 开减少动态及关触觉；4 浅深色分别读字幕与错误。
通过条件：命中区≥48dp；语义顺序正确，焦点可恢复；放大后选项不丢含义；减少空间运动仍可完成；普通文本对比≥4.5:1，大字≥3:1，为本项目设计目标。
证据：辅助功能设置、读屏录屏、对比工具数据；不能只用截图推断读屏通过。
12 性能 负载与测试可信度
QA28 客户端帧与资源趋势
映射 UI 性能目标 P07  |  默认状态 未执行
前置：两台 iPhone、两台不同性能/厂商 Android；记录实际系统版本。
步骤：每台 profile/release 运行视频+面板+列表+旋转，热身 1min、记录 5min；另连续运行30min观察内存趋势，循环进出房间20次；比较减少模糊前后。
通过条件：60Hz UI/raster 各自 p95≤16.7ms；120Hz 按实际刷新率预算约8.3ms另报；记录长帧和超预算率；无持续增长的播放器/订阅；目标未达记录瓶颈而非改口径。
证据：原始 frame timeline、设备温度/功耗模式、内存曲线与视频解码帧；高刷未测不写通过。
QA29 服务负载与异步埋点
映射 P08 P10 A15  |  默认状态 未执行
前置：100个三人房、300 WSS；实际资源配置固定；AI 用桩、CDN 分测。
步骤：逐级升到全局100命令/s，记录事件扇出；热身5min稳态15min；稳态持续补建房间替代终态房，保持100个活跃房；另做5min重连风暴。对比埋点开关及接收端持续429/503。
通过条件：正确性不变量零失败；队列有界可恢复；埋点按10s/20条批发、单批≤50条/64KiB、内存200条/磁盘1MiB；不阻塞交互。延迟目标按下一段验收。
证据：负载脚本与请求混合、样本数、p50/p95/p99、拒绝和错误分母、outbox积压曲线。
QA30 测试断言的有效性
映射 T01—T12 D01—D15 A01—A15  |  默认状态 未执行
前置：核心测试已能运行，独立人工 golden fixtures。
步骤：定向移除鉴权、幂等或 epoch 检查；将截止比较取反；允许重复 settlement；依次跑对应用例，再还原实现。
通过条件：每个非等价变异必须让指定测试失败；存活变异解释或补断言；禁止仅检查200/非空、把全部依赖mock掉或失败后无条件重试转绿。
证据：变异diff、预期失败测试与实际日志；保留首次失败，记录 flaky 根因。
性能拟定门槛：同区域正常网络下命令提交回执 p95≤300ms、p99≤1s，提交至授权事件应用并可见 p95≤500ms；不含 AI 与视频下载。此为 C1 设计测试目标，非实测/SLA；采样同时报错误率与尾延迟，不删除超时样本。容量不足可降低公布支持规模，但不得降低一致性与隔离标准。

缺陷分级
S0：秘密泄露、数据破坏、越权写、重复结算或广泛不可用，立即停止发布与相关测试扩散。S1：核心链路无法完成、恢复失败、真机崩溃、无法操作的布局，必须修复。S2：有可靠绕行的局部功能问题，可由负责人记录范围与修复期限后决定是否放行。S3：非阻断外观问题，进入明确排期。

失败与回滚
发现异常先保存 trace、room、版本和最近有效水位。回滚应用前确认新 schema 向后兼容；不兼容时停止变更并恢复兼容版本，禁止盲目 down 迁移。撤回内容指针只影响新房；安全 blocked 按已定义规则挂起旧房。数据库恢复是独立灾难操作，不把它当日常发布回滚。
个人开发可由同一人执行开发、验证和签收，但须分别留下实现证据与复核记录。AI 可以生成测试草案、整理日志，不能以自评“已完成”替代实测。

QA31 邀请与原子换角
映射 P01、D02、A04，初始 NOT_RUN。邀请码在 24h 边界前后校验，开局/关闭/轮换旧码即无效；大厅空闲过期独立测试，期限测试使用持续有效操作的 lobby fixture。两个已选角色成员请求交换，分别接受/拒绝/取消/30s到期；并发 accept/start/ready/第三人选角。断言双方角色原子交换、取消准备、无重复角色、过期无效果，非参与者不能决定交换。留 DB 行、事件与三端截图。
QA32 投票展示与媒体阶段
映射 P02/P05/P07、A09/A13，初始 NOT_RUN。未公开 C3 进入决策：display_options 可显示安全禁用项，options 不含 publish，强行投票拒绝且无秘密字段；有 C3 时集合冻结并按规则结算。开场确认后只解锁本人的角色片段。探索结束必须播放中场，确认齐全后才起 45s 投票；五分钟未齐挂起、恢复新等待窗口；ending 全离线仍完成。抓取 phase_id、timer_generation、媒体授权及 deadline。
QA33 后台登录与幂等

持续负载
QA29 的100个活跃三人房需按完成速率补建，登录/建房流量单独报告；不得热身后让房间全部结束再测空服务。稳态业务混合建议 chat 40%、vote/改票30%、合法探索与协作20%、确认/生命周期10%，按当前阶段选择合法命令；无法达到该混合须记录实际比例及原因。均匀限速避免聊天超过每成员5秒3次；无效攻击流量另测，不用大量拒绝充当100有效命令/s。
延迟与动画
延迟统计包含全部尝试的成功、业务拒绝、限流与超时分母，单独报告成功命令延迟；N0要求实测RTT≤100ms。服务端提交到客户端事件应用 p95≤500ms，同时拆分收到与应用两段；目标不能用仅收到包代替UI可见。UI截图使用固定设备、字号、主题和无动画状态；字体抗锯齿差异可人工复核，缺文字、遮挡、错误状态均不得豁免。
职责与版本
C1 的主规范：产品定玩法；技术定模块/状态实现；数据定物理字段/事务；接口定线上字段/错误码；UI定视觉/交互；测试定用例与证据。文档版本保持原文件名并统一加C1修订，传输protocol_version=1、内容schema_version=2不因文字修订自动升级，原因是尚无已发布客户端。若已有代码实现旧契约，必须迁移和重生成fixtures。
检查结论的边界
本轮完成文档交叉检查、矛盾修订、排版复核和条目追踪，不代表软件已通过QA01—QA34。浏览器HTML、Flutter真机、WS联调、数据库并发与备份恢复仍待实现后执行。需求、字段或时限变更必须同步主规范与相应QA子项。
