# 1 目标与设计边界
C2 将入戏定义为以 Galgame 和互动影视为呈现方式的多人叙事游戏。玩家在可移动的地点地图中探索，以有限行动力执行推荐操作，也可以提出自己的行动。作者定义世界、秘密与事件，AI 主持解释行动、扮演人物并演绎已经成立的结果。本文面向产品、设计、开发与内容作者，验收依据是本轮用户指令，不代表招聘公司的内部需求。
本轮完整设计包含 Android/iOS 玩家端、React 与 React Flow Web 工作台、DSL、小说改编工具、必要内容管理与运行支持。完整性以这些边界为准，不沿用旧版“一部样片等于全产品”的范围。餐厅样例用于检验规则，不能限制内容只支持餐厅。Web 玩家端、公开匹配、语音、支付和 AI 补位不作本轮实现承诺；触发这些需求时补充相应规则与验收。
旧六篇 C1 被本组 C2 对应文档替代。旧文件名因保留版本身份可能含 v1/v2，正文 C2 和包内索引为准。旧内容 schema_version=2 与 protocol_version=1 不适用于 C2；新版内容 schema_version=3、应用协议 protocol_version=2。Phoenix 传输序列化版本与应用协议版本是不同概念。
# 2 用户与权限
|角色|目标|权限边界|
|玩家|看懂当前情境并影响故事|只收到自身授权的世界投影、个人知识和公共信息|
|房主|组织一场稳定的体验|邀请、开局、请求暂停；没有秘密查看权或强制裁决权|
|作者|制作与维护可玩的世界|编辑有权限的项目，模拟各角色；模拟数据与真实房间隔离|
|审核与发布者|检查内容与版本质量|审核内容 hash，冻结与发布；修改使审核失效|
|维护人员|恢复服务与定位故障|默认仅看脱敏运行信息；受控诊断访问有审计|
作者、审核和维护可由同一开发者承担，但操作权限和审计事件不能混成玩家身份。普通玩家不能通过前端切换角色查看他人视角。
# 3 完整体验旅程
首次打开可浏览目录，参与游戏前建立身份。默认保留旧版游客身份与恢复码机制：首次建号展示一次恢复码并要求用户知晓丢失后无法保证找回；保存入口始终可见，轮换后旧码失效。认证回到原剧本或邀请码目标。提供昵称、头像、音量、字幕、文字速度、减少动态、隐私说明、帮助、反馈与注销入口。
发现页支持搜索、题材和人数筛选；详情展示人数、预计时长、内容提示、媒体需求和当前可用版本。创建私人房间、邀请、选角和准备后锁定内容版本；人数由剧本固定声明，C2 验证范围为 2—4 席，无自动缩放。未开始可以换角，开始后不能换人或旁观。
局内以舞台、对白和推荐行动为主要界面。地图与物品不常驻占满画面。玩家可以一直使用推荐行动完成体验；自由行动提供替代解法和表达，不能成为通关必需。玩家讨论、已知记录阅读不消耗行动力；对 NPC 进行有游戏效果的询问属于行动。仅寒暄且无状态影响的演绎可免费且限频。
结局确定后各人独立阅读，无需等待全员视频完成才保存结果。我的游戏列出进行中、可恢复、已结束及过期记录。复盘默认只显示公共事实与本人经历；揭示全员秘密必须由剧本允许且全部成员明确同意，拒绝不影响已完成结果。

# 6 房间生命周期与内容生命周期
房间从 lobby 进入 active，active 的运行子阶段是 opening、planning、resolving、presentation，结局状态为 ending；suspended 保存未完成局，finished 与 abandoned 为终态。暂停保留剩余时间，不重置行动力。原班组继续、控制设备接管、掉线与结局读完的具体规则由 D02 统一定义。
内容从 draft 到 validated、reviewed、published。发布产物不可变，项目另开草稿；新房锁定当前发布版本，旧房不自动升级。普通撤回不影响旧房；安全封禁暂停未结算房并撤销素材访问。作者可归档项目，但被房间引用的版本须按保留规则保留。
# 7 产品指标与非功能目标
完成率=finished 房间数/已开局房间数，按内容版本与开局日期分组，abandoned 和 suspended 分开报告。预设操作覆盖率衡量只使用推荐操作是否可完成样例，不要求所有玩家都不用自由行动。自由行动拒绝率按明确不可行、需澄清、系统故障分别统计，不能把系统故障当玩家错误。
建议目标：正常网络下提交回执 p95≤300ms；结算提交至授权视图应用 p95≤500ms；AI 行动判断 8s 内完成或降级。数值是待实测的工程门槛，D11 定义环境与样本。内容目标为新用户无需知道 DSL 或跑团术语也能完成首个预设行动。可用性测试以五名首次体验者进行任务观察，不声称具有统计代表性。
埋点不采集私有正文、输入原文或恢复码；事件包含匿名会话、内容版本、动作类别、耗时与结果。异步分批、失败有界缓存，不阻塞交互。开发阶段可以按依赖分批落地，但本文件能力不能随开发批次从设计中消失。
