# 1 两类AI任务
在线主持与离线改编使用不同上下文和权限。主持处理玩家当前可见情境下的意图理解、NPC演绎和结果描述；改编处理完整授权小说和作者草稿，可以提出新剧情但不能未经审核发布。两者通过结构化结果与确定性业务服务交接，不向模型开放数据库或任意代码执行。
玩家自由输入不是提示词编辑器。输入中的指令、小说里的系统提示和检索材料均为不可信内容，放入资料区并明确来源。模型输出先解析Schema再验语义，最多一次结构修复，失败使用固定文案和预设操作，不能无限循环产生费用。
# 2 在线判断流水线
收到文本后先做长度、频率和房间状态检查。构建上下文仅含本人已知信息、当前可观察对象、公开规则、可用行动与模板；作者给NPC的私密真相在服务端先投影为本轮允许表达的事实，不能让面向玩家的自由文本生成器读取整本谜底后只靠提示词保密。
模型返回status、mapped_action_id或template_id、target_id、slots、reason_safe、risk_summary。feasible表示可交给规则服务验证，不是已执行。Elixir核对目标标签、位置、物品、费用范围和效果模板，生成冻结提案。模型不自行报价超过模板范围，不写任意effects。
clarify用于缺少目标或方法，例如“我要打开它”；返回一个具体问题和可选对象，不扣点。rejected用于违反已知物理条件或超出模板的操作，解释已知理由并给最多两条替代操作。敏感秘密不能作为拒绝理由泄露。用户撤回后取消任务；迟到输出丢弃或作为未确认提案，不执行。
# 3 结果演绎与NPC
结算后生成器只接收授权事实、允许语气、当前叙事风格及需保留的确定性摘要。输出不得改变行动成功失败、获得物品、费用、伤害或谜底。UI中结构化结果卡始终显示服务端事实，模型文字即使矛盾也不能掩盖它；事实检查失败用模板叙述替换。
NPC台词允许个性化措辞，但知识边界由角色可透露事实集合控制。NPC可以按剧本说谎，须有明确的lie_fact和受众配置，不能由模型临时编造改变谜题。普通寒暄不改变状态；有交换、承诺或说服效果的对话进入行动提案流程。
# 4 成本 延迟与降级
在线判断目标8s，响应预算建议输入≤6000 tokens、输出≤800 tokens；这是项目限额建议，实施时按实际供应商token规则计量。每分钟每成员6次提案，每房同时最多seat_count个判断任务，同一玩家只保留一个有效判断。触及预算显示预设操作可继续，不阻塞整局。
结果叙述失败使用已授权的固定摘要；模型不可用不影响预设通关。模型供应商、模型版本、参数和提示版本写入任务记录但不写入公开玩家消息。费用按任务和房间聚合，单价来自部署配置，未选择供应商前不承诺实际每局成本。
# 5 小说改编流程与中间产物
|阶段|输入与输出|人工检查点|
|导入分章|正文→章节段落ID及内容hash|修正章界、重复页眉和缺失正文|
|事实抽取|逐章→人物、地点、事件、物品与引用|同名异人、别名、叙事时间|
|全书统一|局部事实→实体表与时间线|矛盾保留为待审，禁止静默择一|
|可玩性改编|统一事实→角色分工、地点图、预设动作与替代解法|原文/推断/新增分开接受|
|DSL生成|获选方案→schema3草稿|验证引用、受众、费用和结局|
|修复与试玩|错误报告→最小patch|人工锁定字段不自动覆盖|
事实记录包含source_id、chapter_id、paragraph_start/end、quote短摘录或hash、provenance=explicit/inferred/adapted。跨度引用可回到原文查看，不要求把全篇原文复制进每个节点。原文事实和新创作的分支都可成为正式内容，但发布前作者必须知道哪些是新编。
长篇采用逐章任务和全局索引，不将整本书一次塞入上下文。任务依赖DAG按input_hash缓存，修改一章使依赖它的人物关系和事件失效，未受影响结果复用。保留每个阶段检查点，浏览器退出不取消服务器任务。
# 6 修订与任务契约
改编结果为ChangeSet：base_revision、source_hash、operations、provenance、warnings。operation包括entity_id、field、before_hash、after、source_refs和reason。应用时做三方比较：当前字段等于before才可自动写；人工locked字段跳过；冲突逐项展示并由作者选择。删除有引用实体必须同步修改引用或拒绝。
任务重试创建attempt，保留旧attempt证据。取消后worker的generation失效，不能把完成回调重新变成功；重试只处理失败依赖。结果查看、下载、接受部分修改、重新编辑与重新校验均有入口W03。不得只提供“生成中”的临时页面而无法找回结果。
# 7 AI评估与发布门槛
在线评估集至少包含正常映射、歧义澄清、无物品、地点错误、预算不足、旧提案、越权秘密、提示注入、NPC谎言边界和供应商超时。关键门槛：越权状态写与秘密canary泄露为零；结构可解析率、可行性分类与人工标签一致率分别记录，建议普通任务准确率≥95%，不可据此放行任何关键泄露。
改编评估按实体消歧、来源定位正确率、明确事实保留、推断标记、可玩路径、人工字段保护分别打分。抽样人工核对至少每章关键事件与全部终局因果链，不能只让另一个模型给通过分。评估fixtures见examples/ai_eval.json，实际模型运行状态为NOT_RUN。
# 8 运营与故障
记录任务耗时、重试、费用、模型版本、拒绝类别与安全过滤结果；默认不记录玩家正文到监控。故障排查需要正文时采用短期授权查看与审计，并按D05七天期限清理。供应商变更先跑同一评估集与灰度流量，必要时关闭自由判断保留预设体验。AI反馈入口让玩家报告误判，报告不自动改变规则。
