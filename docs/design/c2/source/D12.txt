# 1 环境与责任
环境分本地、测试、预发布、生产，各自数据库、对象桶、AI密钥与身份互相隔离。禁止把生产玩家秘密复制到本地评估，使用合成fixtures。个人开发可以同时承担作者、发布和维护责任，但发布记录必须留下实施者和复核步骤。
配置包含数据库连接、服务身份、对象存储、允许来源、token密钥、AI供应商与预算、任务并发、Schema/协议支持版本、内容指针和保留政策。启动时校验必需配置并拒绝带默认密钥运行。secret来自环境密钥管理，不写DSL、客户端或源码。
# 2 构建与发布
流水线执行静态检查→规则/协议测试→Schema与内容校验→客户端构建→预发布多人试玩→数据库expand迁移→部署兼容服务→切换新房内容指针→小范围观察。数据库contract删除在旧客户端与C1房退出窗口后单独执行。
发布记录包含App/Core/Worker SHA、依赖锁文件、DB migration ID、content_hash、schema_version、protocol_version、资产manifest、模型与提示版本。任一必要error或S0/S1失败停止发布，不能为了上线删除测试。真正生产部署不由本轮文档生成自动执行。
# 3 C1到C2迁移
C1有固定阶段、角色行动和线索，没有作者明确的地图及行动点。转换器应保留原ID和来源路径，把公共开场/中场转换成媒体屏障，把投票转换为显式事件，原有角色行动移入候选地点。缺失地图与费用进入人工待审清单，禁止自动假设各角色在不同地点或统一费用。
已发布C1包只读保留，转换生成C2草稿；经过地图补全、成本校准、受众检查和预设通关后才能发布。C1活动房继续旧规则至终态；新房只用明确选择的C2版本。服务端维护engine_version和protocol路由，客户端升级不意味着旧房语义迁移。
无法继续维护旧引擎时，先停止C1新房、通知存档恢复截止并导出可读结果，等待活动局清空；不能在已付权益规则未明确时直接销毁房间。迁移报告记录旧/新hash、映射、未决项与人工确认，重跑相同输入产物一致。
# 4 监控与产品事件
|信号|建议告警|处置|
|命令错误与延迟|5min错误率>1%或p95超目标|区分业务拒绝与系统错误，查看版本与DB|
|outbox积压|最老未投递>10s持续1min|检查投递worker与慢连接，必要时resync|
|房间owner冲突|任何fencing拒绝异常增长|暂停异常owner，检查租约，不绕过epoch|
|AI失败与成本|5min失败率>20%或预算耗尽|关闭自由判断，保留预设操作|
|素材失败|同asset连续失败集中出现|切摘要，撤新房版本或重建变体|
|秘密或越权报告|单个确认事件|立即安全处置、封禁内容或关闭入口|
告警数值是建议初始配置，需要依据实测基线调优。日志使用trace_id、room_id脱敏摘要、command_id、release hash，不写token、恢复码、小说全文或秘密正文。支持工具只显示授权诊断，不直接让运营以玩家身份进入房间。
埋点事件包括story_open、room_created、room_started、action_queued、action_resolved、proposal_result、room_suspended、room_finished、media_fallback、editor_validation。按10s或20条异步投递，单批≤50条/64KiB，内存200条、磁盘1MiB上限；超限丢非关键分析并计数，不能卡住操作。规则审计走服务器事务记录，不依赖可能丢失的前端埋点。
# 5 故障手册
数据库故障：停止写入并显示重试，不允许内存继续结算；恢复后比对owner_epoch和最后提交水位。Phoenix节点故障：新owner获取租约，从快照+事件恢复，旧owner写入被拒。AI故障：取消过期判断，提示可使用预设选项；长任务保留检查点。
CDN故障：签名重取一次后切授权文字摘要，仍允许media.complete(summary)。规则循环：回滚本步并挂起房间，保存诊断trace，不能自动跳过事件继续。被封禁内容：撤销新房入口，未结局挂起并告知，已结局只按允许范围保留复盘。
连接风暴：加入随机退避、短期门限与队列上限，优先已存在房间恢复。玩家提交结果未知：查command_id与receipt水位，不让客服建议重新点十次。
# 6 备份与恢复
数据库持续归档与定期快照，对象存储启用版本和manifest；恢复码hash、身份与内容引用一致备份。独立保存注销擦除清单，恢复旧备份后先重放擦除，再开放服务。生产恢复在隔离环境演练，确认媒体hash和引用有效。
步骤：冻结写入并记录故障点→恢复数据库/对象→校验最后提交与引用→轮换recovery_epoch、租约和敏感凭证→挂起未结局房→重放擦除与幂等墓碑→原成员重新认证续局→对照监控与抽样事实。目标RPO≤5min/RTO≤60min，记录实际值和缺失事务，失败不填PASS。
# 7 回滚与结束服务
日常回滚应用或内容指针，数据库保持expand兼容结构；不盲目执行破坏性down迁移。已有房间内容版本不可替换，修复引擎必须兼容旧规则或提供明确迁移。AI模型回滚同步提示版本，不能只换模型名而保留不兼容输出。
结束服务须停止新房、告知恢复窗口、允许用户取得本人可见历史、停止新生成、按保留政策清理并撤销凭证。内容作者可导出JSON与布局、素材清单和来源记录，不能导出其他项目或玩家秘密。支付若启用需追加权益与退款处置，当前不伪造对应商业承诺。
