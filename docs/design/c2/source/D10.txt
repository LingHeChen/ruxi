# 1 资产范围
素材服务于场景舞台、人物、行动反馈和媒体叙事。资产清单见contracts/assets.csv，样例提供文字与几何占位，可在缺少真实美术和视频时检查玩法；不把占位称为最终素材。完整资产覆盖场景背景、人物立绘/表情、物品图标、地点缩略图、字幕、配音、环境声、音效、转场及封面。
每个资产记录asset_id、kind、source、rights_note、sha256、variants、audience、status、duration_ms、dimensions、locale与fallback。文件名仅辅助人工检索，绑定使用asset_id，不从目录名推导权限。用户上传资源不默认拥有商业使用权，作者填写来源并审核后发布。
# 2 规格与变体
|类型|建议交付规格|适配与替代|
|背景|横版1920×1080，重要区域另给焦点框|竖屏裁切保持人物/交互区域；完整描述替代|
|立绘|透明PNG/WebP，约1600px高|统一脚底锚点、头部安全区及表情ID；姓名与台词替代|
|视频|H.264/AAC MP4，1080p与720p，另带字幕|实际目标设备验证；失败用同受众摘要|
|配音|母版WAV 48kHz；分发AAC|对白ID对齐，关闭配音仍保留全部文本|
|音效与环境|母版WAV，循环点与响度记录|静音不丢游戏规则；重要声音有文字提示|
|字幕|UTF-8 WebVTT及对白结构数据|起止毫秒、speaker、locale；不得含未授权旁白|
|图标与地图标记|SVG或多倍率位图|具有标签，不单靠色彩和图形识别|
数值为资产制作建议，不是SDK能力承诺。导入器检查容器、编码、时长、分辨率和大小；解码失败显示具体资源ID，禁止发布必需但无有效替代的资产。
# 3 叙事时间线
cue包含id、audience、kind、asset_id或text、speaker、blocking、summary、order。同一授权叙事队列按order展示；世界事件seq用于状态应用，cue阅读位置独立。后台前台切换暂停本地媒体，不重置房间计时；公共屏障由D02管理。
普通场景转场240ms淡入淡出；视频转场先确认首帧可用再切换，失败保留背景和字幕，不黑屏等待。配音与对白同ID，快速补全文字不叠加播放音频；跳过停止当前音频并进入下一cue。自动播放遇选择停止，历史回看不再次发媒体完成或行动命令。
多人公共片段可以使用服务端start_at锚点，客户端通过RTT估计偏差；私人对白不强同步。公共片段允许个人选择摘要完成，屏障等待的是理解确认而非统一播放位置。不能为追赶队友反复seek造成明显抖动。
# 4 资源生命周期
uploaded→processing→ready/failed→bound→published。转码失败可重试原文件，修改源文件形成新资产而非覆盖旧hash。替换前列出引用的草稿与发布版本；草稿可批量重绑，已发布版本不可修改，只能发新版本。孤立上传30天无引用可清理，保留与版权记录按项目政策执行。
播放只预加载当前地点与已知相邻地点的授权资源，不预取隐藏结局或其他角色秘密片段。缓存key包含asset hash与受众授权版本，注销清理受限缓存；已下载内容无法保证撤销，隐私设计不能仅依赖短期URL。
# 5 内容生产清单
餐厅示例需要餐厅、走廊、后厨三张背景，服务员与三名玩家角色展示图，餐具、灭火器、电源箱图标，两段结局图/文字，对白文本与环境声。已有几何背景和文字足够验证交互，但正式发行前需按清单制作或授权实际资产。
每条关键调查至少有成功与已调查反馈，可能失败的行动有失败文案；每个地点有空状态与无可行操作提示；每个必需视频有摘要。资产检查在发布校验中关联D08受众和D02事件，不单独看文件能否播放。
# 6 验收
QA19验证错误编码、丢失变体、替换影响、版权来源缺失和私有URL访问。QA11验证后台恢复、布局切换播放器实例数、字幕与音量、自动播放停止条件；QA12验证减少动态和大字。正式设备适配矩阵待D11执行，HTML背景和假媒体状态不代表真实解码性能。
