# 1 验证范围与证据
设计验收与产品实现验收分开。本轮可执行验证包括文档引用、DSL样例、有限参考引擎、HTML原型和DOCX排版。真实Flutter、React Flow运行环境、Phoenix集群、PostgreSQL事务、模型供应商和移动设备尚未部署，相关用例默认NOT_RUN。不能用文档存在或模型自评代替真实测试。
每条用例记录Run ID、环境、代码SHA、内容hash、设备/系统、前置状态、操作、预期与实际、证据路径及PASS/FAIL/BLOCKED/NOT_RUN。N/A必须有范围依据，不从分母中隐去失败。发布要求关键安全/一致性与主体验全通过，开放S0/S1为零。

# 3 规则与契约测试
生产Elixir引擎与离线参考解释器运行相同golden样例，比较行动点、地点、知识、world变量、终局和事件顺序。生成式测试只使用合法类型的随机序列，检查行动点非负、唯一物品单所有者、结局唯一及秘密不跨受众。任何失败保留seed与最小操作序列。
Schema测试包含valid和invalid文件；未知引用虽能过JSON形状检查，必须被语义校验拒绝。HTTP契约与WS envelope分别测试，额外跑Phoenix五元组编码/解码及join/heartbeat；仅JSON parse通过不能算联调通过。
状态变化测试必须断言数据库提交事实与客户端授权结果，不只断言200或非空。用定向变异移除幂等、鉴权、epoch、预算检查，相关用例必须变红；不要求对纯视觉参数做无价值镜像测试。
# 4 UI与框架验证
浏览器原型测试在390×844、1024×768及1440×900验证导航、操作、取消、面板、输入、保存、恢复和减少动态。实际移动补测360×800、低高度横屏及平板分屏；宽度变化不重新创建播放器、WS订阅或命令ID。
Flutter目标样例验证拖动吸附、输入草稿与布局状态，不含真实播放器；媒体插件联调必须再验证音频焦点、硬件解码、后台/来电及内存。React Flow样例需在真实工程锁定依赖后验证节点关联与布局保存，原生HTML模拟不能代替。
# 5 AI评估方法
在线数据集逐条标注应判定状态、允许的模板ID与禁止泄露字段；以人工标注为准。普通映射建议准确率≥95%，危险越权/秘密泄露必须为零。报告样本量、各类别混淆矩阵与失败例，不只给总体平均值。模型切换后完整重跑。
小说改编评估以章为抽样单位，并对所有关键结局因果全检；来源指针错误、把补写当原文和覆盖人工锁定均为阻断问题。模型自动评审仅作为线索，发布前作者实际试玩和审核不可省略。
# 6 性能与可靠性
服务基线：100个三人活跃房、300连接、同区域RTT≤100ms，热身5min稳态15min，持续补建已结束房；业务混合以合法阶段命令为主。回执p95≤300ms、p99≤1s，提交到授权视图应用p95≤500ms；同时报告超时、拒绝和错误率分母，AI任务和视频下载分测。
客户端真机profile/release记录5min舞台视频+面板+布局切换，60Hz UI/raster p95≤16.7ms，另报长帧占比和30min内存趋势。120Hz仅在实际支持设备另测，不声称框架天然达到。AI8s超时降级仍可完成预设操作。
恢复演练RPO≤5min、RTO≤60min，以最后可恢复提交点与原成员可继续游戏为终点；备份成功日志不能代替恢复演练。故障注入覆盖事务前后、outbox投递、租约更换及worker迟到。
# 7 发布门槛与缺陷处理
S0为秘密泄露、越权写、数据破坏或重复结局；立即停止新增房间并调查。S1为主路径不可完成、恢复失败、核心UI不可操作；修复后才能发布。S2有可靠绕行，记录负责人、期限与影响；S3外观问题进入排期。关键权限/规则用例不可豁免。
