# 入戏场景语音数据与通信协议

## 1 契约边界与版本
沿用现有 /api/v2 与 Bearer 认证，新增 voice_protocol_version=1 和 scene_voice_v1 能力位，不擅自改动 C3 protocol_version=3 或 Phoenix vsn。语音控制不是游戏行动，不携带 step_id，不通过占行动名额的 room.command 执行；它通过独立 HTTP 端点和成员私有语音事件协调。
HTTP 的 room_id 来自路径，member_id 来自登录成员映射，control_epoch 来自当前控制设备；不得让客户端提交 location_id、faction_id、rtc_room_id 来选择目标。所有授权依据最新权威世界。未知或无权房间统一 404 TARGET_UNAVAILABLE，不透露隐藏场景是否存在。
权威字段定义见 contracts/voice.schema.json，接口路径和响应见 contracts/openapi.json；它们是本功能增量契约，不替代现有全量 API。JSON Schema 只校验结构，跨房权限、时序、幂等和可见性必须由服务端实现。examples/wire.json 提供同一套字段的可校验样例。
## 2 数据实体与约束
|实体及主键|字段与约束|生命周期|
|voice_room_policy room_id|release_hash、enabled、scope=scene；开局快照不可变|随房间保留，草稿不修改活动局|
|voice_channel room_id scene_id|generation、provider_room_id、status、revision；物理 ID 唯一|代数单调增，旧 ID 永不复用|
|voice_participation room_id member_id|enabled、device_id、control_epoch、restricted_until；一成员仅一控制端|本局有效，登出或离局置 off|
|voice_lease lease_id|room/member/channel/generation、rtc_uid、state、expires_at、token_expires_at、last_seen_at|同成员最多一个有效租约，Token 本文不入库|
|voice_transition transition_id|execution_id、owner_epoch、affected_channels、phase、attempts、deadline|prepared→retiring→fenced→committed 或 blocked|
|voice_outbox event_id|room/member/voice_seq、projection_revision、safe_payload|事务提交后投递，不含凭证|
|voice_request room/member/request_id|action、fingerprint、result_ref、created_at|24 小时幂等窗口，不存 Token|
|voice_usage lease_id segment_id|join_at、leave_at、source、confidence、provider_ref|关闭区间对账，不使用麦克风开关计时|
外键必须包含 room_id 或受该局约束的 channel_id。active 租约唯一性用事务及数据库约束共同保证。关闭事件使用 max(current_revision,event_revision) 合并，不能让迟到 joined 重开 closed。RTC UID 是随机假名；角色名称从当前授权投影解析，不作为供应商用户信息广播。
世界移动的 voice_transition 与 execution_id 绑定；纯语音控制则 execution_id 为 null，按 transition_id 幂等，不占游戏步骤。AP、道具、知识仍属于原世界表，不在语音表重复。回收失败后恢复用新 generation，outbox 允许重复投递。
## 3 保留与隐私
客户端持久化仅音量、按住说话及自动压低 BGM 偏好；本局参与意愿由服务端维护。Token 仅内存，退出、换设备、后台和身份失效时清除。不开录音、转写和声纹；电平只在当前设备短暂用于说话指示，不上传分析。
本功能建议初始保留：详细租约与回收审计 30 天，幂等记录 24 小时，去标识的按日用量汇总 180 天；它们是运营默认设计，不是法定期限声明。终局立即停止 RTC；30 天后删除设备与成员映射，汇总只留日期、平台和用量。注销进入现有删除流程，清理本功能偏好与身份映射，争议保留项按既有明确政策处理并审计。
禁记字段包括 Token、AppKey、原始音频、场景真名、秘密身份及举报自由文本的分析副本。日志只允许 trace_id、内部任务标识、错误类别、耗时和代数。举报内容走既有受限工单，不进入通用埋点。
## 4 HTTP 操作
本节语音控制请求使用同一 Request 信封：voice_protocol_version、request_id、control_epoch、expected_revision、action、body。request_id 为 UUID，expected_revision 是本人 voice_revision。服务端按该成员串行执行；参与意愿、资格、控制设备或频道代数变化时递增 voice_revision，心跳及纯 SDK 观测不递增；STALE_REVISION 后获取 state，以新 request_id 提交用户仍希望执行的操作，不能改写旧请求。
|方法与路径|输入|结果|
|GET /api/v2/rooms/{room_id}/voice|Bearer|200 State，当前本人状态和授权可见成员|
|POST /api/v2/rooms/{room_id}/voice/requests|Request，action=participation|202 Receipt；body.enabled true 加入，false 退出|
|同一 POST|action=grant，body 空对象|200 Grant 或 409 NOT_READY，不改变参与意愿|
|同一 POST|action=heartbeat，body.lease_id|200 Receipt，延长 30 秒租约；过期不复活|
|同一 POST|action=renew，body.lease_id|200 Grant，新 Token 仍绑定同一有效租约|
|同一 POST|action=client_state，body.lease_id 与 status|202 Receipt，只记录 connected/failed/left 观测|
Grant 仅当前本人控制端领取，须等待本地世界应用到其 world_revision；状态 waiting 不返回供应商参数。HTTP 200 Grant 包含 world_revision、lease_id、generation、provider、app_id、rtc_room_id、rtc_uid、token、token_expires_at、lease_expires_at、voice_revision；响应 Cache-Control: no-store。客户端收到后必须再核对当前 revision 和 generation，过期响应直接丢弃。
相同 request_id 同参数重复：participation、heartbeat、client_state 返回原回执而不重复变化，heartbeat 不延长第二次；grant/renew 重新检查当前授权，仍有效时可重签同租约 Token，token_expires_at 不超过首次该请求记录的截止点，已失效返回 LEASE_REVOKED。同键异参返回 IDEMPOTENCY_CONFLICT，客户端不自动换 ID 隐藏错误。
Grant 失败不消耗 AP；客户端 2 秒没收到回执显示等待，8 秒后通过 GET state 确认，再按原 request_id 重试。离线退出本机立即停止；服务端参与 off 成功受理后进入回收，即使凭证回收未完成也不允许重新 grant。
## 5 状态投影与 WS 事件
State 包含 world_revision、voice_protocol_version、voice_revision、voice_seq、participation、status、reason、generation、lease_id、members。status 枚举为 off、unavailable、waiting、connecting、connected、switching、reconnecting、suspended、failed。无活动频道时 generation 与 lease_id 为 null。members 仅当前已授权可见且参与语音的成员摘要：member_id、display_name、rtc_uid、mic_state、connection_state；rtc_uid 未授权时为 null，当前代数授权后用于匹配 RTC 流，不附其他频道信息。
服务端不能单凭客户端说话或关麦回报证明实际发布权限；mic_state 仅 UI 提示，可为 unknown。说话电平是本地 RTC 事件映射到授权 UID 后更新，不写入可靠 WS 事件。
成员私有 Phoenix 流新增 voice.state，载荷为完整 State，加 cause（participation、scene_change、network、policy、ended）和与现有世界关联的 world_revision。外层 world_revision 必须等于 State.world_revision。事件可重复且至少一次投递，按 voice_seq 单调应用。断线或序列缺口 GET state 获取当前完整快照，旧序号丢弃；无须补发历史 Token。scene_change 的新 State 仅在世界提交后发送，客户端先应用对应 world_revision，避免仍显示旧场景却听到新场景。
voice_revision 用于并发控制，voice_seq 用于事件顺序，generation 用于物理房间代数，control_epoch 用于设备控制权，四者不能混用。grant 与 renew 不推进 voice_revision，首次租约创建绑定当时已固定的资格 revision，voice_seq 可因连接状态变化递增；本轮并行请求必须读取最新 state 后重试。
## 6 错误与重试
错误沿用 error.code、safe_message、retryable、trace_id，可附 current_revision 与 retry_after_ms；不得回显 Token 或目标隐藏信息。HTTP 401 AUTH_REQUIRED、404 TARGET_UNAVAILABLE、409 STALE_REVISION/CONTROL_LOST/NOT_READY/LEASE_REVOKED/IDEMPOTENCY_CONFLICT、422 INPUT_INVALID、429 RATE_LIMITED、503 VOICE_UNAVAILABLE。
只有网络超时、429 与 503 允许自动指数退避，按 1、2、4 秒并加抖动，最多 3 次，之后用户重试。自动重试使用原 request_id；授权撤销、设备失权和参数错误不重试。客户端禁止后台排队开麦；连接恢复必须由当前状态重新允许。
服务端每成员每分钟 30 次普通控制请求，heartbeat/renew 独立限额每分钟 10 次；重复幂等查询也限流。平台级发 Token 峰值按容量试验设置，封禁任务使用 V2 的账户共享预算，不能被玩家频繁点击耗尽。
## 7 DSL 和配置
contracts/policy.schema.json 描述独立扩展片段：communication.voice.enabled 为布尔，scope 固定 scene；locations 是 id 与 voice.mode 的列表。合并原发布 DSL 后再检查 location 引用、角色可见性及非语音推进路径。缺失片段默认为 disabled，未知 scope 拒绝发布；不可让 AI 改编直接启用全局语音。
Token 120 秒、租约 30 秒、心跳 10 秒、续签提前 45 秒、封禁 180 秒、回收超时 8 秒、封禁预算 20 QPS 均在 examples/config.json 集中定义。生产修改需保持封禁时长不少于 Token 最大有效期加时钟裕量，并重新验证回收与成本。作者只配置语音可用性，不编辑供应商参数和安全时限。
## 8 管理与举报增量契约
POST /api/v2/rooms/{room_id}/voice/reports 使用 Report：request_id、target_member_id、reason_code（harassment、noise、other）、可选 description（最多1000字符）。服务端核对举报人本局身份以及目标在最近10分钟确有同场景授权交集，返回202与report_id；同键异参409，无交集统一404。截图或音频不在此接口上传。举报保留期限沿用受限工单策略，不能复制到分析日志。
GET /api/v2/admin/rooms/{room_id}/voice 返回 AdminState：room_id、enabled、channels（channel_ref、generation、status）、pending_transition_ids、estimated_person_minutes、estimated_cost_yuan、restricted_member_ids；channel_ref 为内部不透明标识，不包含场景正文。仅带 voice:read 权限的运营可调用，房主无权。
POST /api/v2/admin/rooms/{room_id}/voice/requests 使用 AdminRequest：request_id、action、reason，以及按 action 区分的 body。restrict_member 与 release_member 的 body 为 member_id；retry_retirement 为 transition_id；disable_room 为空对象。需要 voice:manage 权限，返回202与operation_id。restrict_member 仅收回整局语音，非游戏封号；release_member 只恢复资格，不自动恢复麦克风。重试任务不得跳过回收条件；disable_room 先停止新授权再走回收。服务端日志记录管理者和理由，不接受客户端传入管理者身份。
新增管理请求以管理员身份与 request_id 为幂等键，异参返回409；同参返回原 operation_id。GET /api/v2/admin/rooms/{room_id}/voice/operations/{operation_id} 返回 queued、running、succeeded、failed 及安全错误码，用于界面轮询；2秒起、最大10秒间隔，结束即停止，支持按trace_id查审计。未知操作或跨房统一404，无权限403；错误结构沿用第6节。

## 9 数据访问与索引
基于 C2 PostgreSQL 与 Ecto 迁移方式新增表，保持 expand 后兼容读旧，不直接修改历史房间快照。voice_channel 的 (room_id,scene_id) 唯一；物理代数历史独立保存在 voice_channel_generation，键为 (channel_id,generation)，provider_room_id 全局唯一，记录 max_token_expires_at 与 retired_at。当前表只指向最新代数，回收任务引用历史代数，不能覆盖旧房号而失去回收目标。
voice_lease 对 (room_id,member_id) 在 issued/connected 状态建立条件唯一索引；过期扫描先锁记录并显式改 expired，再允许新租约，不使用 now() 作为索引条件。建立 state/expires_at 扫描索引，rtc_uid 全局唯一，以及 (room_id,member_id,created_at) 排障索引。外键 (room_id,member_id) 指向现有房间成员的复合键。
voice_transition 对 execution_id 唯一，phase/updated_at 用于未完成任务恢复；voice_outbox 对 (room_id,member_id,voice_seq) 唯一；voice_request 对 (room_id,member_id,request_id) 唯一；usage 对 (lease_id,segment_id) 唯一并检查 leave_at 不早于 join_at。Request fingerprint 包含 action/body/control_epoch/expected_revision，采用规范化 JSON 摘要，不含 Token。
本局禁用、成员受限及控制权变化均在同一权威房间锁下修改资格并提交 retirement outbox。只读状态由当前世界和租约构建，不依赖供应商回调实时更新位置。供应商回调重复不重复记用量，迟到 leave 修正未知结束区间时保留修订来源。
