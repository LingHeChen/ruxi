# 入戏场景语音测试验收与运维

## 1 交付边界与验收责任
本文件规定真实产品上线前必须执行的验收；本轮交付的文档、契约和 HTML 验证不能替代 Flutter 与火山联调。产品负责规则及体验，客户端负责权限与音频路由，后端负责资格及回收，运维负责供应商账号、密钥、配额和对账。全部集成用例初始标为 NOT_RUN。
基线为 C3 当前三份文档与已有功能；本期新增真人同场景语音。原 AP、密码、骰子、地图、秘密知识、单人本和旧房恢复必须回归。关键泄密、旧凭证复用、误扣 AP、后台录音、错误自动开麦与世界状态破坏均为阻断项。
## 2 验收场景
|用例与能力|操作|预期|
|VA01 同场景与跨局隔离|同局 A/B 同场景，C 另一场景，D 另一局|只有 A/B 互听，猜房号无法取得授权|
|VA02 独处与加入|一人选择语音，第二人随后选择|先 waiting 无 RTC，随后连接且双方关麦|
|VA03 正常移动|开麦时移动并立即在目的地发声|旧权限回收后才提交位置，新会话默认关麦|
|VA04 快速返回|A→B→A 并重放第一次 Token|新身份与代数生效，旧 Token 不可收听|
|VA05 撤权中断|封禁超时或返回 429|步挂起，无到达、无 AP 扣除；重试原计划|
|VA06 原子组移动|多人同一步 group_move|先回收相关旧房，成员一起提交，仅一次组到达|
|VA07 重复与乱序|重复 request、迟到 Grant 和旧 SDK callback|无多租约、无恢复旧音频、无重复开麦|
|VA08 WS 与 RTC 分离故障|只断 WS，RTC 网络仍通|本机停音，服务端租约到期回收，不继续续签|
|VA09 设备与系统权限|拒绝麦克风，换设备，来电和后台|可听不采集；旧设备失权；返回默认关麦|
|VA10 隐藏信息|隐藏地点、潜伏角色、秘密阵营|无其他场景名单；不对称可见场景发布禁语音|
|VA11 关闭与终局|退出语音、登出、暂停、解散和结局|回收含已发未用 Token，无幽灵驻留计费|
|VA12 音频体验|蓝牙切换、外放、BGM、旁白并播|无持续回声，设备变更关麦，压低与恢复正确|
|VA13 无障碍与布局|390/768/1440 宽、200% 字体、减动效|无溢出遮挡，键盘和读屏可操作，不重复播报电平|
|VA14 权限与管理|房主尝试旁听，运营暂停资格，玩家举报|房主无越权，运营审计，举报不自动录音|
|VA15 崩溃恢复|计划、封禁、世界提交、outbox 各点断电|同一 execution 恢复，旧房不复用，AP 不重扣|
|VA16 成本对账|6 人通话后分散、静音、离局|按实际在 RTC 人分钟估算，静音不计为免费|
|VA17 旧客户端与单人|无能力客户端、旧内容、单人本|仍能文字游玩；无默认开语音和真人 RTC 费用|
|VA18 旧玩法回归|密码、骰子、隐藏地图、轮次暂停|结果及知识权限不变，语音不占行动名额|
详细步骤、故障注入点与证据字段在 verification/acceptance.json。每次执行必须记录代码 SHA、SDK 版本、平台系统、网络条件、RTC AppID 环境、开始时间、实际结果与脱敏证据。凭证重放测试只在隔离测试应用执行，保留结果而不保存原始 Token。
## 3 质量目标与验证方式
质量指标为目标，不是供应商承诺。基础条件为中国大陆同地域、RTT 不高于 100ms、无持续丢包；覆盖 100 个三人游戏房、最多 300 个语音成员，以及集中步结束导致的频道重建突发。另测 300ms RTT、10% 丢包及网络切换，不把弱网实验与基础目标混算。
下列时延目标适用于封禁请求低于账户预算的稳定负载；集中步结束超过预算时单独记录排队与挂起率，不承诺同一时延。100 房同时重建最多 300 个频道可能超出 8 秒，须验证安全挂起与恢复，容量不足时增配供应商配额或减少启用语音的新房准入。首次 RTC 授权到可听 p95 不超过 2 秒；正常换场景请求回收到新场景可听 p95 不超过 3 秒；本机关麦触发到停止采集 p95 不超过 100ms。封禁请求排队 p95 不超过 500ms，8 秒未完成按 V2 挂起。第三方资源撤销确认条件必须先经实测确定，不能以超时到期代替。
强隔离测试用测试音源在撤权前后发送可区分标记，接收端记录声学或 PCM 时间线，核对世界提交时刻、旧房停止、新房发声及旧凭证重放。必须证实旧成员无法接收新频道媒体；撤权前已采集尾音单列分布。若供应商异步生效且无法证明 fence_complete，应阻止上线并调整适配器或供应商方案。
Flutter 以目标中端 Android、iPhone 真机测 30 分钟通话，包含页面切换和剧情动画；目标语音 UI 不引入持续主线程卡顿，60Hz 设备大部分帧在 16.7ms 内完成。记录耗电、温升、CPU、内存、音频路由恢复和首帧，不用浏览器原型推断原生性能。桌面与 Web 单独验证 SDK 支持，不假设 Flutter 原生插件自动支持 Web。
## 4 成本与预算
普通端纯音频公开单价 0.007 元/人分钟；微信与抖音小程序端为 0.009 元/人分钟。用户在 RTC 房间内即计费，静音或无人说话不免费，多路音频按单路计算。计费以自然日累计时长口径和供应商账单为准，不把每次短连接都向上取整为一分钟。来源 S1。
估算费用为实际 RTC 人分钟总和乘单价。6 人连续 60 分钟约 2.52 元，6 人连续 120 分钟约 5.04 元；只是基础语音，不含折扣或额外服务。场景拆分本身不省钱；少于 2 位参与者时不驻留才减少用量。两位仅收听者仍连接计费，本期不做按语音电平频繁进退房。
租约和已确认 join/leave 形成费用估算区间，未知离开时间用保守上界并标 confidence=estimated；云账单为最终事实。按日比较估算与账单，差异超过 max(10%,10元) 提醒人工检查驻留、后台机器人和异常续签，不自动修改账单。新增语音无用户侧扣费接口。
每环境配置 daily_budget_yuan，预警默认 80%，达到 100% 停止新的语音加入并通知运营；已有通话给予 60 秒提示后回收，游戏可文字继续。预算是应用估算控制，不承诺云账单硬上限。控制与回收故障按 V2 的安全流程处理，不能为了省钱跳过关闭确认。
## 5 监控 埋点与支持
服务端记录 join_success_rate、join_latency、scene_switch_latency、revoke_latency、revoke_failures、lease_orphans、token_issue_denied、provider_429、rtc_person_minutes 和 budget_ratio。按平台及 SDK 版本聚合，不按秘密场景名称或阵营分析。5 分钟加入失败率超过 5% 且样本不少于 20 报警；任一回收任务超过 8 秒即高优先级报警。
客户端分析事件异步分批投递：每 20 条或 10 秒一批，内存队列上限 200 条，满时丢弃低优先级 UI 事件；不阻塞音频回调、动画或游戏命令。只上报操作类别、结果、耗时和匿名关联 ID，不传音频、电平序列、成员名单或剧情。服务端安全审计独立可靠写入，不依赖可丢的分析队列。
支持人员从 VP06 按 trace_id 查看授权状态、任务时间线和估算用量，无权听音、读隐藏剧情或复制 Token。操作仅允许重试回收、关闭本局语音、暂停成员语音资格及恢复资格；每次记录操作者、理由、时间和目标。恢复资格仍需玩家主动开麦。
## 6 部署 迁移与回滚
测试与生产使用独立 RTC AppID、密钥、预算与回调配置。服务端先上线增量表和端点，旧客户端忽略能力；新客户端声明 scene_voice_v1；新发布剧本显式启用；旧活动房不自动打开语音。先白名单测试剧本，再 5%、25%、100% 新房逐步放量，各阶段检查权限回收、失败率和账单。
上线前完成 Token 绑定、过期行为、房间封禁传播语义、QPS 配额、Flutter 平台支持、后台行为与音频插件冲突验证。没有实际仓库版本信息时先做映射盘点，不根据本文件猜线上数据库或协议版本。Android/iOS 为本版必要验证端；桌面/Web 未通过平台验收则隐藏该端语音入口，游戏其余功能仍可用。
回滚先停止新授权，逐一回收当前物理房间，再把语音开关关闭；保持新增表与旧协议兼容，不反向删除正在处理的审计。冻结中的世界计划待安全收口后继续。密钥轮换前停止发旧凭证并回收旧会话；确认无活动依赖后撤销旧密钥。备份不包含 Token，恢复后默认无有效语音租约。
## 7 文档与附件一致性验收
本期交付 V1 产品交互、V2 技术、V3 数据协议、V4 测试运维；contracts 为机器可校验字段，source 为可维护正文；原型展示关键 UI 与状态但不接 RTC。覆盖表将需求追到页面、规则、契约和 VA 用例。审查范围为当前 C3 文档和本期全部附件，未读取实际项目源码，不能声称完成产品代码审查或上线验收。
统一检查必须核对：作用域 scene、单人不接真人 RTC、2 人启用、默认关麦、120/30/10/45/180/8 秒参数、频道代数、世界提交前回收、无 Token 持久化、幂等与乱序、计费口径和延期能力。实际修复记录和附件验证结果见 verification/review.txt。
