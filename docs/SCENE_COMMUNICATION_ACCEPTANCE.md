# 房间文字与场景语音

## 使用

本地启动 `sh scripts/start_core.sh`，脚本读取未提交的 `.local/rtc.env`。玩家进入房间后，点击右上角「同伴交流」，切换文字/语音页签。文字支持全房间、当前场景及配置了阵营的阵营频道，不消耗行动点。历史消息按发送当时的可见成员保存，不随后来移动场景扩大可见范围。

语音需剧本发布版本启用、房间开始游戏、至少两名同场景在线玩家主动加入。首次加入仅收听，打开麦克风才申请权限。支持按住说话、成员本地静音、收听音量和背景音乐降低。退出、后台、控制权变更或连接失效停止音频。单人和不支持 RTC 的桌面平台仍可使用文字。

新发布的《潮汐旅馆：第九声钟响》已启用场景语音。旧房间绑定旧发布版本，不会自动迁移；请新建房间邀请同伴。

制作台的故事设置允许开启场景语音、单独禁用场景。管理端「房间交流」提供状态、参与人分钟估算、举报、成员限制、房间关闭和退役重试。reviewer/publisher 可查看，publisher 可操作，操作原因必填并审计。系统不录音。

## 配置与部署

`.local/rtc.env` 包含 VOLC_RTC_APP_ID、VOLC_RTC_APP_KEY、VOLC_ACCESS_KEY_ID、VOLC_SECRET_ACCESS_KEY。生产部署使用服务端环境变量，不能将 AppKey 或云 API 密钥注入前端。仅将服务端签发的短期房间/用户绑定 Token 交给 RTC SDK；不写入日志、数据库、浏览器持久存储或房间事件。

控制台必须开启连麦鉴权。启用签发还要求 VOLC_RTC_FENCE_VERIFICATION_ID 与 `services/core/priv/voice/rtc-evidence.json` 的验证编号一致，且 AppID 哈希一致。切换 App 或 SDK 后需重新验证，不能复制本次证据假定新环境已通过。无有效证据或配置时禁用语音，文字不受影响。

Web 使用官方 @volcengine/rtc 4.69.3，Android/iOS 使用官方 volc_engine_rtc 3.60.8。Web bundle 的许可证随 `web/licenses/volcengine-rtc.txt` 分发。Web 生产环境需要 HTTPS、可用麦克风、WebSocket 和 RTC 网络连通。原生端已接入并完成静态检查，尚未完成真机验证。

## 隔离策略与当前限制

正常撤权使用 BanRoomUser 加上 GetRoomOnlineUsers：封禁成功后立即查询完整在线名单，确认目标 UID 已离开（整频道撤权则确认名单为空）。仅 API 成功回应、客户端自报退出或不完整查询都不能重新签发目标玩家的语音授权。查询失败时回退到已验证的 Token 强制过期：最长 120 秒，再留 30 秒余量。普通场景移动直接提交地图与剧情，不等待语音撤权；只在旧 UID 确认离开后签发新场景语音授权。房间结束、暂停及整频道关闭保留待提交计划；已经退役的频道不会复用。同场景、同控制设备且参与权限未变化的普通断线保留原频道。

成员封禁、退出登录、取消语音及控制权转移按 UID 撤权，不关闭其他玩家的共享频道，不暂停世界。撤权任务持久化到 ruxi.c2_voice_revocations，包含尚未过期的历史连接；目标玩家重新授权前须完成撤权，并使用新 UID。管理员限制保存在房间成员记录中，刷新、重新登录或供应商临时封禁到期都不会解除，只有管理员解除后允许重新授权。供应商封禁覆盖旧 Token 的有效期即可，业务限制持续有效。场景移动仅撤销移动成员在旧场景的 UID，其他玩家不退出旧频道。供应商异常时该玩家的新语音授权仍可能等待约 150 秒，正常游玩和地图移动继续进行。

每日费用按参与人分钟估算，默认限额 50 元，达到限额停止新准入，已有会话进入退役宽限。估算不是供应商账单。没有设备、负载及账单对账验证，不应视为运营认证。

## 麦克风权限弹窗修复

浏览器权限弹窗及窗口失焦对应 Flutter inactive：只停止麦克风，不退出 RTC，不发送 client_state:left。只有 hidden/paused/detached 才停止收听并退出。权限窗口期间取消的开麦不会在窗口关闭后自动恢复，需要重新点击。麦克风权限/采集错误保留收听连接；供应商踢出、Token 失效等仍停止会话。

新增 Flutter 生命周期回归及三项 Web bridge 回归验证权限拒绝、权限等待中失焦和真实频道移除。独立 RTC 探针不得保留连接生产开发数据库的后台游戏维护进程；本次清理了遗留探针进程，正常维护任务已经完成受影响房间的退役。

## 刷新与返回页面恢复

语音参与意愿以鉴权后的服务端房间状态为准。普通刷新、页面后台、RTC 断开及短暂 WebSocket 中断不改变当前场景授权，只解除本次连接租约，不创建频道退役计划、不冻结游戏、不让其他同伴退房。返回时重新获取短期授权、默认闭麦。大厅仍不连接 RTC；明确“取消语音参与”后不会自动恢复。

同一有效场景 generation 内，成员 RTC UID 保持稳定，新连接使用新的 lease_id。真实 Web SDK 验证同 UID 重入会替换旧 RTC 连接。旧租约的退出、续签和回调不能修改新租约；旧 WebSocket 关闭仅匹配自己的 socket_ref。不同场景 generation 使用不同物理房间与 UID，不沿用已经撤销的频道。

权限名单基于当前场景、参与意愿、限制状态、设备和控制代次，在线状态单独用于显示与首次准入。首次建立频道仍要求至少两位在线成员主动加入；同伴短暂掉线期间已连接者保留收听。无有效租约的空闲频道等已发 Token 全部确认过期后直接关闭，不冻结世界。后台仍停止本地采集和播放；重连不会自动开麦。

关闭房间语音确认相关旧频道退役；换场景、成员取消参与、封禁、控制权转移、退出登录及账户撤销只撤销该成员的旧 UID。已断开成员过去签发的 Token 也计入撤权任务，不能通过断开页面绕过限制。退出未参与语音的成员不会影响其他玩家。

验证：Elixir 全套 125 项通过；Flutter 最近全套 59 项通过，2 项既有真实服务测试跳过，本次交流组件 12 项通过且 Web 构建通过。新增覆盖旧 socket 延迟关闭、旧 lease 请求拒绝、仅租约过期、断开后移动仍须围栏、空闲频道关闭、退出登录及非参与者登出。

真实双 Chromium、合成麦克风验证：页面刷新、重新建立私有 WebSocket、保留参与意愿、原场景频道快速重新授权、恢复远端音频均通过。两次恢复实测分别约 6 秒和 5 秒，同伴没有 failed/disconnected 事件。额外测试保留旧 RTC 连接，让新连接同 UID 重入：旧连接被替换，迟到旧 lease 的退出被服务端以 LEASE_REVOKED 拒绝，新连接音频正常且同伴未中断。旧方案曾需 159 秒，此等待已从普通断线恢复流程移除。

以上是本地 Web 样本，不是延迟 SLA。供应商无法确认撤权时仍有最长约 150 秒的过期兜底，Android/iOS 快速恢复与同 UID 替换行为仍需真机验证。费用基于租约及本地离开报告估算，恶意客户端与供应商账单差异未验收，不能视为账单硬限额。


## 按成员撤权与快速重新授权

Web 三客户端实测：按 UID 封禁后，目标旧 Token 重入返回 USER_FORBIDDEN；GetRoomOnlineUsers 只保留其他两名玩家；同伴没有 failed/disconnected 事件且继续传输音频。解除限制后原频道使用新 UID 重新授权。真实退出登录、恢复同一身份、建立新私有 WebSocket、重新选择参与语音后拿到新授权，此前实现的 8.7 秒重进和 8.8 秒场景等待已移除。最新三人实测重新登录约 576 毫秒拿到授权，真实 action.submit 和 round.end 后约 82 毫秒提交新场景位置；旧 UID 重入仍返回 USER_FORBIDDEN，留在原场景的玩家保留频道和连接。

本次后端全套 125 项、Flutter 交流组件 12 项通过，Flutter analyze 无问题，Web release 构建通过。新回归覆盖封禁跨重连持久生效、解除限制换 UID、撤权未知只阻塞目标成员、状态查询等待真实完成和过期兜底。旧媒体凭证未落盘。当前以服务端完整在线查询确认离开，不设置固定传播等待。延迟样本不是 SLA；换 App/SDK 后重新验证。

接口依据：[BanRoomUser](https://docs.volcengine.com/docs/6348/1188353?lang=zh)、[官方 Go SDK 的 GetRoomOnlineUsers 响应定义](https://github.com/volcengine/volc-sdk-golang/blob/main/service/rtc/v20231101/model.go)。


最新四人双场景 RTC 实测：两名同伴已在海景餐厅频道，另一名玩家从接待厅移动过去。地图/剧情位置在 47 毫秒内提交，实际 RTC 加入目标频道耗时约 1.98 秒，约 2.70 秒收到该频道正在说话的同伴音频回调。原场景玩家保持原 generation 和连接，目标场景复用既有频道。没有固定等待或为移动关闭整个频道。

撤权任务新增快速唤醒，1 秒周期扫描仅作漏通知及失败重试的兜底。客户端在一次刷新期间收到更新会排队立即再取最新状态，避免刚收到撤权完成通知却仍等下一个 3 秒轮询。此竞态新增组件回归覆盖。
